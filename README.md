# ממ"ן 11 – שאלה 2: מתכנן המסיבות כאוטומט תאי

## הרצה
דרוש Python 3 עם `numpy` ו-`matplotlib` (`pip install numpy matplotlib`).

```
python main.py                  # ריצה ראשית: MAIN_MATRIX, 2000 דורות, התוצאות בתיקייה output/
python main.py --live           # אותה ריצה בחלון גרפי חי (ממשק גרפי)
python main.py --matrix cities  # מטריצה אחרת: main, table1, cities, chase, wallflowers, knot
python main.py --matrix chase --live   # אפשר לשלב אפשרויות
python main.py --seed 7         # מיקום התחלתי אקראי אחר
python experiments.py           # כל הניסויים לסעיפים 6 ו-7 (כ-2 דקות)
python test_automaton.py        # בדיקות שהחוקים תקינים (כ-10 שניות)
```

## הקבצים
| קובץ | תפקיד |
|------|-------|
| `constants.py` | כל הקבועים (גודל השריג, השולחן, המטריצות והרשימה MATRICES, הפאזות...) – אין מספרים "קסומים" בקוד |
| `automaton.py` | האוטומט עצמו: מצב התאים, חוק A (התפשטות מרחקים), חוק B (תנועה ב-3 פאזות). אין בו גרפיקה |
| `metrics.py` | מדידת איכות הקונפיגורציה (stress) – "צופה חיצוני", לא חלק מהחוקים |
| `visualize.py` | כל הגרפיקה (תמונות מצב, גרפים, ממשק חי) – מופרד מחוקי האוטומט כנדרש |
| `main.py` | הריצה הראשית |
| `experiments.py` | ניסויים: 20 מיקומים התחלתיים (סעיף 6ב) ומטריצות מעניינות (סעיף 7) |
| `test_automaton.py` | בדיקות: אף בליין לא נעלם או מוכפל, השולחן קבוע, צעדים של תא אחד לכל היותר, וחוק A נותן מרחק צ'בישב מדויק |
| `SPEC.md` | מסמך התכנון וההחלטות (D1–D7) |

## הנחות והחלטות עיקריות
- מרחק צ'בישב: `max(|Δx|, |Δy|)`, ערכי המטריצה הם מרחקים בתאים (ללא קנה מידה).
- `0` = "כמה שיותר קרוב". אי אפשר לחלוק תא, ולכן המרחק הקטן ביותר האפשרי הוא 1, ו-0 נשמר כ-1 בטעינת המטריצה. `-1` = "אדיש" (האורח לא מתחשב ביעד הזה).
- אסור לשני אורחים להיות באותו תא; אי אפשר לדרוך על השולחן או לצאת מהחדר.
- שובר שוויון: נשארים במקום אלא אם יש שכן טוב יותר ממש; בין שכנים שקולים – קודם צעד ישר, אחר כך אלכסוני, בסדר קבוע.

## למי שלא מכיר numpy
בקוד אין לולאה על התאים. כל שורת numpy מפעילה את אותו חוק מקומי על **כל** התאים בבת אחת –
וזה בדיוק העדכון הסינכרוני של אוטומט תאי. הסבר מפורט בראש `automaton.py`.
